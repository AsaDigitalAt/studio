# **App Name**: Cosmic Observer

## Core Features:

- Instagram URL Analysis: Analyze an Instagram post, reel, profile, or story URL to determine its type.
- Sentiment Analysis: Uses a tool to Analyze the sentiment of the Instagram post's comments to extract the overall tone.
- Manual Tagging: Manually add or remove usernames associated with the Instagram post.
- Tagging Runs History: Access to tagging history for streamlined data retrieval and consistency.
- Data Archiving: Archive sentiment data and user tags into the Firestore.

## Style Guidelines:

- Primary color: Deep indigo (#4F3A93) to evoke a sense of cosmic mystery and depth.
- Background color: Dark gray (#212429) to provide contrast and a clean, modern feel.
- Accent color: Electric purple (#BE95FF) to highlight interactive elements and create visual interest.
- Body and headline font: 'Space Grotesk' sans-serif for a futuristic, computerized aesthetic.
- Use minimalist line icons to maintain a clean and modern UI.
- Ensure consistent spacing and alignment across all UI elements.
- Employ subtle, smooth transitions for interactive elements to enhance user engagement without distraction.
